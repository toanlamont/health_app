1. Overview & Tech Stack

HeartBeat la ung dung theo doi suc khoe ca nhan, tinh nang chinh la do nhip tim bang camera truoc dien thoai su dung ky thuat Photoplethysmography (PPG). Ngoai ra app con ho tro tinh BMI, theo doi lich su chi so suc khoe, bieu do thong ke, va he thong nhac nho.

Mobile App

Flutter 3.x — Cross-platform iOS/Android. Camera plugin cho PPG, fl_chart cho bieu do, local notifications cho nhac nho.

Backend API

FastAPI + Python 3.11 — Async REST API, JWT auth, auto-gen OpenAPI docs. Xu ly du lieu suc khoe va sync giua cac thiet bi.

Database

PostgreSQL 15 — Luu tru user profiles, heart rate records, health metrics. SQLAlchemy ORM + Alembic migration.

Infrastructure

Docker + Nginx — Containerized deployment. Redis cho caching/rate limiting. Firebase cho push notifications.

3. Heart Rate Measurement (PPG)

Photoplethysmography (PPG) la ky thuat quang hoc do su thay doi the tich mau trong mao mach. Khi dat ngon tay len camera truoc, anh sang tu flash/man hinh chieu qua da — moi nhip tim lam thay doi luong mau hap thu anh sang, tao ra tin hieu tuan hoan co the do duoc tu camera frames.

PPG Processing Pipeline

1
Camera Capture Mo camera truoc, bat flash/tang sang man hinh. Capture frame lien tuc o 30fps. User dat ngon tay che kin camera.
2
Frame Preprocessing Trich xuat gia tri trung binh kenh Red va Green tu moi frame. Kenh Red nhay nhat voi su thay doi hemoglobin.
3
Signal Filtering Ap dung Bandpass Filter (0.7Hz – 3.5Hz, tuong duong 42–210 BPM) de loai bo nhieu. Dung Butterworth filter bac 4.
4
Peak Detection Tim cac dinh (peaks) trong tin hieu da loc. Tinh khoang cach giua cac dinh lien tiep (IBI – Inter-Beat Interval).
5
BPM Calculation BPM = 60 / avg(IBI). Lay trung binh 10 giay cuoi, loai bo outliers. Hien thi ket qua realtime tren UI.

Flutter Implementation Approach

// Core PPG processing flow (Dart)
class PPGProcessor {
  final _buffer = <double>[];       // Raw signal buffer
  final _bpmStream = StreamController<int>.broadcast();

  void processFrame(CameraImage image) {
    // 1. Extract average Red channel intensity
    final avgRed = _extractRedChannel(image);
    _buffer.add(avgRed);

    if (_buffer.length >= 300) {       // 10s at 30fps
      // 2. Bandpass filter 0.7-3.5 Hz
      final filtered = _butterworthFilter(_buffer);
      // 3. Find peaks
      final peaks = _detectPeaks(filtered);
      // 4. Calculate BPM
      final bpm = _calculateBPM(peaks);
      _bpmStream.add(bpm);
      _buffer.removeRange(0, 30);      // Sliding window
    }
  }
}

7. Features Breakdown

A. Do nhip tim (Core Feature)

Realtime Measurement

Camera preview voi overlay huong dan. Hien thi BPM realtime, waveform animation. Do 15–30 giay.

Result Screen

Hien thi BPM, heart rate zone (rest/normal/elevated/high), do tin cay, thoi gian do. Luu va chia se ket qua.

Heart Rate Zones

Phan loai theo tuoi va gioi tinh: <60 Low, 60–100 Normal, 100–120 Elevated, >120 High (resting).

B. BMI & Health Profile

BMI Calculator

Nhap chieu cao + can nang, tu dong tinh BMI. Hien thi phan loai (gay, binh thuong, thua can, beo phi) voi visual gauge.

Weight Tracking

Ghi nhan can nang hang ngay. Bieu do xu huong can nang theo thoi gian. Canh bao thay doi dot ngot.

C. Lich su & Thong ke

Heart Rate History

Bieu do duong theo 7/30/90 ngay. Hien thi avg, min, max. Filter theo context (resting/active).

Health Report

Bao cao suc khoe hang thang: tong hop nhip tim, BMI, muc tieu dat duoc, streak do lien tuc.

D. Nhac nho & Muc tieu

Smart Reminders

Nhac do nhip tim, uong nuoc (moi 2h), tap the duc. Custom schedule voi cron. Push notification.

Health Goals

Dat muc tieu: can nang, nhip tim muc tieu, uong du nuoc/ngay. Progress bar, deadline, streak tracking.

8. Security & Privacy

Authentication

JWT + Refresh Token. Access token het han sau 1h. Refresh token rotate moi lan dung. Bcrypt hash password.

Data Privacy

Du lieu suc khoe ma hoa AES-256 at rest. HTTPS bat buoc. Raw signal data chi luu khi user dong y. GDPR-ready.

API Security

Rate limiting (100 req/min). Input validation (Pydantic). CORS whitelist. SQL injection protection (ORM). Request signing.

Mobile Security

Token luu trong Secure Storage (Keychain/Keystore). Certificate pinning. Root/jailbreak detection. Obfuscation.
